# Ambulance-Number-Emergency-Response-Mobile-Application
An Expo/React Native app for finding publicly listed ambulance contacts in Nepal.

## Features
- One-tap calls to published ambulance numbers
- Search verified listings by provider, municipality, district, or province
- View the public source for each listed contact

## Ambulance contact data

The app only includes numbers that were found on public provider or local-government pages. The current verified local listings are in Bagmati Province; this is not a complete Nepal-wide directory.

The ambulance short code `102` is listed by Lalitpur Metropolitan City Ward 28 and described as an ambulance dispatch number by [Nepali Times](https://nepalitimes.com/100-101-102-hh5uvzf9). Availability and response coverage can vary, so the app does not promise that it will connect from every village or municipality.

No single current public directory with verified direct ambulance numbers for every village and municipality was found. Missing areas are intentionally not filled with guessed numbers. Please confirm availability and service area when calling. Sources were checked on 2026-11-19.

## Public sources

- [Patan Academy of Health Sciences](https://web.pahs.edu.np/) — publishes the Patan Hospital ambulance number.
- [Lalitpur Metropolitan City, Ward 28 emergency contacts](https://ward28.lmc.gov.np/page/emergency-service) — lists the ambulance short code and a Nepal Ambulance Service contact number.
- [Nepal Ambulance Service contact page](https://nepalambulanceservice.org/contact) — publishes its provider contact number.
